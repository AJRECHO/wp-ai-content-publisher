# WP AI Content Publisher（WordPress AI 内容发布插件）

一个把 RSS 内容用 AI 忠实翻译润色后自动发布到 WordPress 的开源插件。抓取 → 筛选 → AI 改写 → 自动配图设封面 → 打标签 → 定时发布，全流程自动化。所有配置都在后台可视化设置，**开箱即用，无需改代码**。

## 特性

- **AI 改写**：调用 DeepSeek 或任意 OpenAI 兼容的 `chat/completions` 接口，把外文/原文忠实翻译润色成地道中文，自动加标题、标签，不编造事实、不写主观评价（Prompt 可完全自定义）。
- **定时发布**：三种模式——手动 / 每日随机时间 / 每日固定时间；随机模式避免发布过于规律。
- **谷时省钱**：可只在高峰时段之外发布（配合 DeepSeek 谷时 5 折），随机时间点若落在高峰期会自动顺延。
- **分类轮换**：按配置顺序在多个分类间轮换，每个分类独立配置 RSS 源。
- **筛选去重**：标题黑名单（政治/黄赌毒/新闻快讯等，可自定义）、时效过滤、正文长度过滤、URL 去重。
- **自动配图**：原文配图自动转存到 WordPress 媒体库（零依赖）或自定义图床；特色图自动设置，列表页美观。
- **完整后台**：7 个标签页的管理界面，含连接测试、候选预览、配置导入导出、发布日志、一键删除。
- **REST API**：状态、发布、测试、预览、日志、删除等接口，方便接入外部定时任务。
- **安全**：密钥不硬编码、配置导出自动脱敏、接口密钥鉴权、nonce 校验、输出转义。

## 安装

1. 下载插件zip，保持目录结构解压到 `wp-content/plugins/wp-ai-content-publisher/`。
   - 目录结构应为：`wp-ai-content-publisher.php` + `includes/` + `assets/` + `uninstall.php`
2. 在 WordPress 后台「插件」中启用。
3. 左侧菜单出现「WP AI 内容发布」，进入开始配置。

> 也可用 GitHub 仓库直接安装（如托管在 WP 插件目录）。

## 快速开始（3 步）

1. **AI 设置**：填入 API Key。默认接口是 DeepSeek：
   - 接口地址：`https://api.deepseek.com/v1/chat/completions`
   - 模型：`deepseek-chat`
   - 点「测试连接」确认可用。
   - 用其他服务商（OpenAI / 通义 / 本地模型等）只要兼容 OpenAI chat 格式，改接口地址和模型名即可。
2. **内容源**：设置参与轮换的分类（如 `科技,数码,开发`），并在每个分类下填入 RSS 地址（每行一个）。
3. **发布规则**：选择发布模式（推荐「每日随机时间」），设置每日上限和时效天数，保存。

配置完成后，插件会按计划自动发布。想立即验证，去「概览」页点「立即发布一篇」。

## REST API

接口前缀：`/wp-json/aicp/v1/`。鉴权二选一：登录管理员，或请求头带 `X-AICP-Key: 后台生成的密钥`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/status` | 运行状态 |
| POST | `/publish?force=1&hint=关键词` | 触发发布（force 忽略限额，hint 精准选文） |
| POST | `/test-api` | 测试 AI 连接 |
| GET | `/preview?cat=科技` | 预览候选文章 |
| GET | `/log` | 发布日志 |
| POST | `/reset?what=log\|all` | 重置数据 |
| POST | `/delete-post` | 删除文章（body: `post_id`） |

配合系统 cron 可完全脱离访问触发发布（插件已内置 WP-Cron 的 5 分钟任务；如需绝对可靠，可在服务器加一条每 5 分钟请求 `wp-cron.php` 的 crontab）。

## 定时机制说明

插件启用后注册一个「每 5 分钟」的 WP-Cron 任务检查是否到发布时间。WP-Cron 依赖站点访问触发，低流量站点可能延迟。若要完全不依赖访问：

```bash
# 在服务器 crontab 加（把域名换成自己的）
*/5 * * * * curl -s -o /dev/null https://example.com/wp-cron.php?doing_wp_cron
```

（可选）在 `wp-config.php` 加 `define('DISABLE_WP_CRON', true);` 后，发布将完全由上面的系统任务驱动。

## 配置导入 / 导出

「工具与日志」页可导出配置为 JSON。**导出不含 API Key 和 REST 密钥**，可安全分享。导入时也不会覆盖现有的这两个密钥。

## 常见问题

**Q：点了立即发布没反应？**
A：先确认 AI 设置里密钥已填且测试连接通过；再看是否有「RSS 源」和候选文章（用「预览候选文章」检查）；发布记录会说明跳过原因（如正文过短、无封面、命中黑名单）。

**Q：想先审核再发？**
A：发布规则里把「发布后状态」改为「存为草稿」。

**Q：封面想统一风格？**
A：图片与封面页把「封面来源」改为「自定义图库」，填入一批你精选的图片直链（每行一个），发布时随机选一张。

**Q：图片想放对象存储？**
A：存储方式选「自定义目录」，填服务器上的绝对路径和对应外链 URL 前缀。默认方式存 WP 媒体库，最简单。

**Q：支持哪些 AI？**
A：任何兼容 OpenAI `chat/completions` 的接口。DeepSeek、OpenAI、通义千问、Moonshot、本地 vLLM/Ollama（OpenAI 兼容模式）等都可以。

## 隐私与安全

- API Key、REST 密钥只存本地数据库，不随配置导出，不发送到除 AI 接口外的任何地方。
- RSS 原文与图片仅用于生成你自己的文章。
- 所有后台输出均转义，接口均有鉴权。
